# Preferințe prospectare decidenți sponsorizare (Asociația „Salvează o inimă”)

Reguli stabilite de utilizator (Vlad / office@salveazaoinima.ro), valabile pentru
skill-ul `prospectare-decidenti-sponsorizare` și pentru orice prospectare de companii.

## Ordinea obligatorie de prioritate a contactelor

Când returnez contacte din **Lusha** și **Apollo.io**, le dau întotdeauna în această ordine:

1. **CSR** — CSR Manager / CSR Director / ESG / Sustainability / Corporate Affairs
2. **HR** — HR Director / HR Manager / People & Culture
3. **Director Economic**
4. **Director Financiar / CFO / Finance Director**

Observații:
- CSR este primul, întotdeauna. Dacă nu există rol de CSR, se trece la HR și așa mai departe.
- Restul funcțiilor (CEO / General Manager / Administrator, Marketing, Comunicare, PR)
  rămân utile, dar se listează **după** cele patru categorii de mai sus.
- Se păstrează regula: maximum 5 contacte per companie, fără contacte fără putere de decizie,
  fără emailuri/telefoane inventate.

Stabilit: 2026-10-02.
